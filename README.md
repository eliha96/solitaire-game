# סוליטר קלאסי (Classic Windows Solitaire) לנייד ולמחשב 🃏

משחק סוליטר (Klondike) קלאסי, מותאם במיוחד למכשירים ניידים ומסכי מגע לצד עכבר במחשב, נטול פרסומות לחלוטין, ומשחזר במדויק את המראה, הצלילים וההתנהגות של סוליטר מ-Windows.

---

## ✨ תכונות מרכזיות

- 🚫 **100% ללא פרסומות וללא מעקב:** חוויית משחק נקייה, שקטה וחלקה.
- 📱 **PWA (Progressive Web App):** פועל כאפליקציה במסך מלא, ופועל גם **אופליין ללא חיבור לאינטרנט**.
- 🃏 **גרירה ושחרור (Drag & Drop) חופשי:** תמיכה מלאה בגרירת קלפים בודדים או ערימות קלפים שלמות, עם החזרה חלקה (Snap-back) אם שוחררו במקום לא חוקי.
- 👆 **Tap-to-Move חכם:** לחיצה אחת על קלף מקפיצה אותו אוטומטית ליעד הטוב ביותר (עדיפות ל-Foundations ולאחר מכן לטור המתאים).
- 👑 **איורי בני מלוכה וערכות עיצוב:** איורי וקטור עשירים עבור נסיך, מלכה ומלך (J, Q, K), עם אפשרות לבחירת ערכת פני קלפים (וינטג' קלאסי של Windows, מודרני נקי, או ג'מבו ענק).
- 🎴 **4 עיצובי גב קלפים נוסטלגיים מ-Windows:** כחול גיאומטרי קלאסי, טירת הלילה, חוף הים והדקל, וזר השושנים.
- 🗂️ **שליפת קלף 1 או 3 קלפים:** תמיכה מלאה במצב Draw 1 ובמצב Draw 3 עם תצוגת מניפה אופקית בקופה.
- 🏆 **מצבי ניקוד:** בחירה בין "מצב רגוע" ללא קנסות זמן לבין "ניקוד אתגרי" הכולל את כל חוקי הניקוד המקוריים של Windows.
- ↩️ **ביטול מהלך (Undo) בלתי מוגבל:** לחצן בולט ונוח לחזרה אחורה בכל שלב.
- 💡 **לחצן רמז (Hint):** הדגשת מהלך מומלץ על הלוח.
- 🌟 **השלמה אוטומטית מרחפת (Auto-Complete):** ברגע שכל הקלפים נחשפו, הקלפים מרחפים ומחליקים למקומם באנימציית תעופה מספקת.
- 🎲 **משחקים פתירים מובטחים (Winnable Deals):** מאגר משחקים שנבדקו מראש למניעת מבוי סתום.
- 🎆 **אנימציית ניצחון מקורית ב-Canvas:** שובל הקלפים המקפצים האייקוני של Windows 95/XP.
- 🔊 **צלילים מובנים ומשוב רטט עדין:** Web Audio API ורטט (Haptics) בכל הנחת קלף.

## 🛠️ טכנולוגיות

- **React 19 + TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Canvas Confetti & HTML5 Canvas**
- **Web Audio API & Haptics API**
- **Service Worker (PWA Offline Cache)**

## 🚀 פיתוח ובנייה מקומית

```bash
# התקנת תלויות
npm install

# הפעלת שרת פיתוח
npm run dev

# הרצת בדיקות יחידה
npx vitest run

# בניית גרסת ייצור
npm run build
```

## 📲 התקנה בסמארטפון (Android / iOS)

1. פותחים את הקישור בדפדפן (למשל Google Chrome באנדרואיד).
2. לוחצים על תפריט שלוש הנקודות (⋮) בפינה העליונה.
3. בוחרים **"הוסף למסך הבית"** (Add to Home screen) או **"התקן אפליקציה"**.
4. המשחק יתווסף למסך הבית כאפליקציה עצמאית, ללא שורת כתובת ומוכנה תמיד למשחק!
