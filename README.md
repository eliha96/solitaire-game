# סוליטר קלאסי (Classic Windows Solitaire) לנייד 🃏

משחק סוליטר (Klondike) קלאסי, מותאם במיוחד למכשירי אנדרואיד ומסכי מגע, נטול פרסומות לחלוטין, ומשחזר במדויק את המראה, הצלילים וההתנהגות של סוליטר מ-Windows.

פותח באהבה במיוחד עבור סבתא, עם דגש על פשטות, נגישות וחוויית משחק מהנה.

---

## ✨ תכונות מרכזיות

- 🚫 **100% ללא פרסומות וללא מעקב:** חוויית משחק נקייה וחלקה.
- 📱 **PWA (Progressive Web App):** פועל כאפליקציה במסך מלא, ופועל גם **אופליין ללא חיבור לאינטרנט**.
- 👆 **Tap-to-Move חכם:** לחיצה אחת על קלף מקפיצה אותו אוטומטית ליעד הטוב ביותר (עדיפות ל-Foundations ולאחר מכן לטור המתאים). אין צורך בגרירה מעייפת באצבע.
- ↩️ **ביטול מהלך (Undo) בלתי מוגבל:** כפתור בולט וברור לחזרה אחורה בכל שלב.
- 💡 **לחצן רמז (Hint):** הדגשת מהלך מומלץ על הלוח.
- 🌟 **השלמה אוטומטית (Auto-Complete):** ברגע שכל הקלפים נחשפו, מופיע כפתור לסיום מהיר ומספק של המשחק.
- 🎲 **משחקים פתירים מובטחים (Winnable Deals):** מאגר משחקים שנבדקו מראש למניעת מבוי סתום.
- 🎴 **4 עיצובי גב קלפים נוסטלגיים מ-Windows:** כחול גיאומטרי קלאסי, טירת הלילה, חוף הים והשמש, וזר השושנים.
- 🎆 **אנימציית ניצחון מקורית ב-Canvas:** שובל הקלפים המקפצים האייקוני של Windows 95/XP.
- 🔊 **צלילים מובנים ומשוב רטט עדין:** Web Audio API ורטט (Haptics) בכל הנחת קלף.

## 📲 התקנה בטלפון של סבתא (Android)

1. פותחים את הקישור בדפדפן **Chrome** בטלפון של סבתא.
2. לוחצים על תפריט שלוש הנקודות (⋮) בפינה העליונה.
3. בוחרים **"הוסף למסך הבית"** (Add to Home screen) או **"התקן אפליקציה"**.
4. המשחק יתווסף למסך הבית כאפליקציה עצמאית, ללא שורת כתובת ומוכנה תמיד למשחק!
